# data/maps.txt and data/items.txt

The map names in `maps.txt` come from the [MapleStory Classic Wiki](https://mapleclassic.wiki/wiki/Category:Maps)
(the `name_en` field of each map page, fetched 2026-10-22). The item names and prices in `items.txt` come from
the same wiki's item and shop tables (fetched 2026-10-23). The wiki's content is licensed
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) by its contributors, and these
lists are shared under the same license. The names themselves are MapleStory's, © Nexon.

Nothing else in this repository is covered by this license.
